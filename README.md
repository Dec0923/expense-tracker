支出保存トラッカー (Expenditure Tracker)
日々の支出を記録し、その時点での「合計支出額」をスナップショットとして履歴保存できる家計管理Webアプリケーションです。

1. 開発の背景・目的

単なる支出メモではなく、**「その時の合計額を記録として確定させる」**機能を重視しました。 日々の支出データは修正や削除を行うことがありますが、「先週末時点での合計はいくらだったか」といった過去の確定した数値をログとして残しておくことで、より家計の推移を実感しやすくすることを目指しました。

2. 実装した主要機能

支出明細の管理: 明細の登録、一覧表示、および不要なデータの削除
リアルタイム集計:
登録された明細に基づく現在の合計支出額の自動計算

合計額の履歴保存: 
その時点の合計額をボタン一つでデータベースへ「記録」として永続化

履歴管理: 
過去に記録した合計額の履歴表示および、不要になった記録の削除

3. 使用技術

(Tech Stack)Backend: Java 17 / Spring Boot 3.x
Frontend: HTML5 (Thymeleaf), CSS3

Database: MySQL 8.x

ORM: MyBatis (XMLレスなアノテーション形式を採用)

Design: モバイルファーストなカード型UIレイアウト

4. こだわり・工夫したポイント

ユーザー体験 (UX):
頻繁に使う「合計の記録」ボタンを視覚的に目立つ緑色で配置。
UIデザインの工夫: 
視認性と操作性を両立させるため、情報をセクションごとに独立させたレイアウトを採用。
各要素に適切な余白（Padding）と角丸（Border-radius）を設定し、モダンで直感的なインターフェースを目指しました。

データベース設計:
流動的な「支出明細データ」と、確定値としての「合計記録データ」を別テーブルで管理。明細を整理（削除）しても過去の記録が消えない仕様にしました。

設計思想:
７日間という限られた時間の中で「確実に動作する最小構成（MVP）」を構築するため、Service層をコントローラーに統合しつつ、データの整合性を担保するよう努めました。
